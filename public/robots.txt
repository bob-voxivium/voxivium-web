# voxivium.com — crawler policy
#
# Policy: permissive, including AI crawlers. Decided by CEO 2026-07-31.
#
# Rationale: this is a marketing site with no proprietary content. Being
# quoted when someone asks an assistant "what is Voxivium" is free
# distribution, and blocking AI crawlers would sit oddly beside a business
# model that sells aggregated sentiment data to AI labs. Revisit only with
# an explicit decision — do not tighten this file incidentally.
#
# Note: crawlers are not blocked from /subscribe here on purpose. Those pages
# carry <meta name="robots" content="noindex">, and a page must be crawlable
# for that directive to be read. Disallowing them would leave them indexable
# by URL alone.
